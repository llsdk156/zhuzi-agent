## 📌 项目全局定位与核心价值（解决谁的什么问题）

在传统高校图书馆特藏古籍与古典文化研学中，普遍面临**“高深隔阂”三重壁垒**：
1. **藏书高深隔绝（可望不可即）**：千余卷理学善本常年存放于高校特藏善本库房，借阅审批流程繁琐，普通本专科生及非专业读者极难亲手翻阅；
2. **文字深奥晦涩（领悟门槛高）**：宋代理学原典微言大义、未加断句，通用大模型容易产生“机械客服腔”或虚构文献的“学术幻觉”；
3. **查借两张皮（线上线下脱节）**：现有数智系统仅能线上问答，与高校图书馆线下真实流通割裂，读者查完原典无法获知实体书在哪个架位、是否可借。

**【考亭云章】** 依托华为云码道 (CodeArts) 全流程研发，实现**“线上大儒解经 ➔ 密闭域 RAG 原典考据 ➔ 毫秒穿透 OPAC 排架号 ➔ 线下直接借走纸质书”**的知借合一闭环！

## 🌟 五大核心功能矩阵

### 1. 📖 大儒第一人称沉浸式讲筵微课
- **庄敬宗风人设**：以南宋理学集大成者朱熹（考亭先生）第一人称自述，融汇浅近文言与雅致白话；
- **同步板书黑板**：讲学过程中实时在“书院黑板”梳理义理要点，测验后加盖朱印颁发研习证书。

### 2. 🔍 密闭域双轨混合 RAG 原典考据（学术零幻觉）
- **真文献引证**：收录 23 部传世经典与特色方志，提问即刻索引至具体卷册、篇章与句读；
- **严密事实对齐**：设置置信度安全门槛，杜绝通用 AI 胡编乱造，文献引证准确率达 100%。

### 3. ⚡ 智慧图书馆 OPAC 接口毫秒级穿透（知借合一）
- **真实馆藏定位**：秒级查询高校图书馆真实在架状态、借阅状态与**六楼专架真实索书号**（如 `B244.71/L42`）；
- **借还提速 90%**：提供一键直达 OPAC 详情页与线下预约书单，打通数字研学到实体流通的“最后一米”。

### 4. 🏛️ WebGL 3D 沧洲立体藏书阁漫游
- **沉浸式 3D 空间**：基于 Three.js 构建宋代木质书架立体交互空间，读者可自由漫游、选书、翻阅原典；
- **轻量低功耗**：纯前端轻量加载，无需专业独显，轻薄笔记本与移动端均可流畅 60FPS 渲染。

### 5. 📜 考亭古风宣纸尺牍文创生图
- **数字文创生成**：智能提炼研习感悟，自适应排版为宋代宣纸毛笔手札并钤盖朱子印章，可一键保存分享。

## 🚀 极简极速复现指南（零门槛运行）

本项目支持三种自适应运行方式，已预置完整的**本地轻量自适应认知引擎**，无需显卡，人人可用：

### 方式一：Windows 电脑一键双击启动（推荐 · 最简单）
1. 双击运行项目根目录下的 **`start.bat`**；
2. 脚本将自动检测环境、补全必要轻量依赖，并**自动唤起浏览器**打开研习馆界面；
3. 访问地址：`http://127.0.0.1:8000/`。

### 方式二：标准 Python 命令行启动
```bash
# 1. 克隆代码仓
git clone https://gitcode.com/lin1235678/zhuzi-agent.git
cd zhuzi-agent

# 2. 安装依赖（清华源极速下载，几十秒即可完成）
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 3. 一键启动服务
python run.py
```

### 方式三：Docker 容器化部署
```bash
docker build -t zhuzi-agent .
docker run -d -p 8000:7860 --name zhuzi-container zhuzi-agent
```

### 方式四：公网在线免密体验
免去本地配置，直接点击公网正式部署地址进行实测：

## 🌐 接口标准与跨平台集成

### 1. OpenAI 兼容问对接口
任何支持配置第三方大模型接口的系统均可无缝挂载：
- **API Endpoint**: `POST /v1/chat/completions`
- **流式传输**: 支持标准 SSE 流式输出（`"stream": true`）

### 2. 超星 / 学习通 AI 助教 Webhook
- **API Endpoint**: `POST /api/supernova/webhook`
- 原生兼容高校在线教学平台 AI 助教，可一键作为通识课程随堂助教使用。

### 3. OPAC 索书号与在馆状态查询
- **API Endpoint**: `GET /api/opac/search?keyword=朱子语类`
- 返回书籍排架号、所在楼层、馆藏地、当前借阅在架状态。
