# 考亭理学书院 · 朱子文化特色智能体

> “字求其训，句索其旨；未得乎前，不敢求乎后。” —— 朱熹《朱子读书法》

本项目是一个融合深厚宋代理学思想、严谨治学工夫与现代人工智能技术的人文教育特色智能体——**【考亭山长 · 朱子先生】**。

系统构建了高精度的朱子典籍混合检索知识库（RAG），支持在本地或云端大模型驱动下，以原汁原味的宋代理学大师口吻为学者解经释惑、指导治学，并提供了一键挂载后续私有特色文献的扩展架构与**超新星/超星平台全协议接入适配器**。

---

## 🌟 核心特色与功能

### 1. 理学人设与宗风底蕴
- **深厚人格化体验**：以南宋理学集大成者朱熹（考亭先生）为原型，言谈持重庄敬、循循善诱、温厚笃实，融汇浅近文言与雅致白话。
- **融通经典思想体系**：
  - **本体认识论**：理气不离、理一分殊（月印万川）、即物穷理、格物致知。
  - **心性工夫论**：心统性情、存天理去私欲、居敬持志、知行相须。
  - **宗规教化论**：白鹿洞书院学规（修身之要、处事之要、接物之要）、紫阳家训与《童蒙须知》。

### 2. “朱子读书法”智能导学工坊
内置朱子六步读书法智能诊断与研习交互：
1. **循序渐进**：小立课程，微加积叠，克制贪多务得。
2. **熟读精思**：字求其训，使其言若出于吾之口；使其意若出于吾之心。
3. **虚心涵泳**：如白纸受墨，洗尽主观成见与浮躁偏见。
4. **切己体察**：句句反求诸自身德行，不做纸上死功夫。
5. **着紧用力**：宽着期限，紧着日程；如撑上水船，一篙不可放缓。
6. **居敬持志**：整饬衣冠，主一无适，立志成圣成贤。

### 3. 双轨文献知识库体系（RAG）
- **首期网络权威精萃库（已内置）**：
  - 《四书章句集注》（《大学章句》《中庸章句》及补传）
  - 《朱子读书法六条详解》
  - 《白鹿洞书院揭示》（教规全文与义理发微）
  - 《朱子家训》与《童蒙须知》
  - 《朱子语类》核心理气心性与知行卷
  - 《朱熹生平考亭闽学文化纲要》
- **特色文献扩展仓（随时挂载）**：
  - 存放目录：`data/custom_corpus/`
  - 支持在 Web 终端界面直接拖拽或上传 `.txt`、`.md` 格式的特色文献（如地方志、族谱、碑刻拓片辑录、古籍点校本），系统自动切块并即时建立检索索引。

## ⚡ 超新星 / 超星平台接入指南

本智能体配备了**多协议自适应网关**，可适配超星泛雅平台、学习通 AI 助教、自建超新星系统或第三方智能体平台：

### 模式一：OpenAI 兼容协议（主流标准推荐）
任何支持配置自定义大模型接口的平台均可直接接入：
- **API 端点**：`POST http://<你的服务器IP>:8000/v1/chat/completions`
- **请求体格式**：
  ```json
  {
    "model": "zhuzi-agent",
    "messages": [
      {"role": "user", "content": "朱子读书法有哪六步？"}
    ],
    "stream": false
  }
  ```
- 支持流式输出（`"stream": true`，符合标准 SSE chunk 规范）。

### 模式二：超新星专属 Webhook 协议
专为教学平台 AI 助教 Webhook 定制，自动平滑兼容 `query`、`question` 等多种字段格式：
- **API 端点**：`POST http://<你的服务器IP>:8000/api/supernova/webhook`
- **通信秘钥**：请求体中的 `token` 或 Headers 中的鉴权凭证（默认：`zhuzi_secret_key_2026`）
- **请求示例**：
  ```json
  {
    "query": "请讲讲白鹿洞书院学规的核心要义",
    "userId": "student_2026",
    "courseId": "chinese_philosophy_101",
    "token": "zhuzi_secret_key_2026"
  }
  ```
- **响应示例**：
  ```json
  {
    "code": 200,
    "message": "success",
    "data": {
      "answer": "诸生所虑者，身心修养与接物处事之本也...",
      "speaker": "考亭山长·朱熹",
      "userId": "student_2026",
      "intent": "academy_rules",
      "sources": [
        {"title": "03_白鹿洞书院揭示_学规.txt", "content": "..."}
      ],
      "timestamp": 1720000000
    }
  }
  ```

### 模式三：学习通微应用 / 网页 iframe 嵌入
可直接将古雅书院风交互 Web 终端嵌入超星课程页面或微应用：
```html
<iframe src="http://<你的服务器IP>:8000/" width="100%" height="800px" frameborder="0"></iframe>
```

## 🚀 运行模式与环境适配（他人使用零门槛指南）

本项目支持三种自适应运行模式，系统会**全自动根据当前运行环境智能切换**，无需人工干预：

### 模式 A：零依赖·全离线原生自适应模式（默认 · 人人可用）
- **适用场景**：将项目发送给同学、老师、评审专家，对方使用的是普通的轻薄本、办公电脑，**没有独立显卡，也没有安装 Ollama 或任何 API Key**。
- **使用方法**：直接双击运行 `start.bat`。
- **体验效果**：内置了完整的考亭书院原生自适应认知引擎与本地典籍知识库，支持多轮姓名记忆、寒暄、读书法诊断、四书析义、白鹿洞规与文人风骨朗诵，内存仅占不到 50MB，毫秒级即开即用！

### 模式 B：本地 GPU 显卡大模型加速模式（个人开发推荐）
- **适用场景**：电脑配备了 NVIDIA 独立显卡（如 RTX 30/40/50 系列）。
- **使用方法**：
  1. 双击运行 `install_local_model.bat`（自动拉取轻量 `qwen2.5:1.5b` 显卡模型，大小仅 986MB）；
  2. 双击 `start.bat` 启动，系统自动检测并启用本地 GPU 全功能大语言模型，享受实时流式生成与自由拓展对话。

### 模式 C：免费 / 商用云端大模型模式（灵活扩展）
- **适用场景**：希望接入云端大模型（如免费的 DeepSeek、阿里云通义千问、硅基流动等）。
- **使用方法**：复制 `.env.example` 为 `.env`，填入对应平台的 `API_KEY` 与 `API_BASE_URL` 即可。

### 模式 D：超新星平台 / 云服务器部署（终极分发方案）
- **适用场景**：将智能体部署在学校实验室或云服务器（如阿里云、腾讯云、校园内网服务器）上。
- **使用方法**：在服务器启动后，直接在超新星/超星平台或学习通后台配置 Webhook 地址（`http://<服务器IP>:8000/api/supernova/webhook`）。
- **体验效果**：全校师生在手机学习通 App 或浏览器上直接点击使用，**所有人都不需要在本地电脑安装任何大模型或配置任何环境**！

## 🛠️ 快速启动指南

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 运行自测脚本
验证典籍检索、多轮对话与智能体推理是否正常：
```bash
python tests/test_rag.py
python tests/test_api.py
```

### 3. 一键启动服务
Windows 用户直接双击 `start.bat`，或在终端执行：
```bash
python run.py
```

启动后在浏览器中打开：**`http://127.0.0.1:8000`** 即可进入考亭理学书院沉浸式问对终端！

## 📜 后续提供特色文献时的使用方法

当您收集整理好特色文献（如点校古籍、地方志文萃、朱子后裔族谱家训等）后：
1. **方式 A（界面直传）**：打开 `http://127.0.0.1:8000`，点击右上角 **“挂载特色文献”** 按钮直接选择上传。
2. **方式 B（文件直投）**：直接将 `.txt` 或 `.md` 文档放入项目中的 `data/custom_corpus/` 文件夹。
3. 智能体将即时读取、自动切块并索引，随后的对话便会实时考引您的专属特色文献！
