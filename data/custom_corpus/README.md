# 特色文献存放仓 (Custom Corpus)

此处为后续存放您所提供的**特色朱子文化文献**目录。

## 支持的文件格式
- **纯文本文件**：`.txt`, `.md`（推荐 UTF-8 编码）
- **富文本及文档**：`.docx`, `.pdf`, `.json`
- **地方志与碑刻拓片辑录**、家谱族规、考亭与白鹿洞书院历史专刊、学术专著或论文摘录等。

## 使用方法
1. 直接将文献文件复制放入本文件夹（`data/custom_corpus/`），或者在 Web 终端界面中点击“上传特色文献”按钮上传。
2. 智能体将在服务启动或刷新时自动扫描本目录，对文献进行分段、分词、提取关键概念，并自动并入向量检索知识库。
3. 问答时，智能体将自动检索并明确标注引用自您的特色文献文件名与段落出处！
